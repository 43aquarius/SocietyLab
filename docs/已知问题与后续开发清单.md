## 三、已知问题（按严重程度）

1. **未经实际运行验证**（最重要）：语法与公式已尽最大努力静态校验，但 Godot 运行时行为（信号时序、资源导入、UI 锚点在不同分辨率下的表现）需要在你的机器上跑一遍。首次打开请先让编辑器完成资源导入。
2. UI 锚点按 1600×900 基准设计并使用 `canvas_items/expand` 拉伸；极窄窗口（<1280）时右侧面板与顶栏可能拥挤。
3. 事件卡最多同时显示 2 张，多余排队；连续大量事件时旧的会被提前顶掉（设计取舍，非 bug）。
4. 战争/革命等剧烈事件目前通过数值与文字表达，没有专属过场动画。
5. 音频为程序化合成（无版权风险），氛围是氛围垫底，尚无旋律性音乐。
6. 快照上限 24 个（约 480 年），超长游戏会丢弃最早快照。
7. 存档名保留中文，但极生僻字符在游戏内可能显示为回退系统字体（已加系统字体回退链，多数平台正常）。
8. `EventSystem` 疫病风险依赖居住拥挤度，小聚落几乎不会疫病（人口 >120 才显著）——低风险而非零风险。

**深度（P1）**

- 双世界并排对比视图（分支 A/B 同屏）
- 参数面板（游戏内改 GameConfig 并热重载）

- 更多统计：人口金字塔、行业结构迁移

**内容（P3）**

- 成就系统与“文明档案”导出
