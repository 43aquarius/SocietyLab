# Society Lab 操作指南

## 一、界面布局

```
┌──────────────────────────────────────────────────────────────┐
│ 顶栏：世界名 · 年份 · 人口 · 存粮 · 社会形态 · 信仰 | 变速 | 编年史/观察者/帮助/菜单 │
├──┬───────────────────────────────────────────────┬──────────┤
│神│                                               │ 右侧信息面板 │
│力│              等距世界（可缩放/平移）            │ 选中对象详情 │
│栏│                                               │          │
│  │                                               │          │
├──┴───────────────────────────────────────────────┴──────────┤
│ 最近事件（点击打开编年史）              底部操作提示            │
└──────────────────────────────────────────────────────────────┘
```

主界面的核心是**世界画面**，不是数据仪表盘。顶栏只保留 6 项关键状态；更多数据在观察者模式（O）里，默认不打扰你。

## 二、相机与观察

| 操作 | 效果 |
|---|---|
| 鼠标滚轮 | 以光标为锚点缩放 |
| 按住左键/中键拖动 | 平移视野（选中神力工具时左键留给施法，可用中键平移） |
| WASD / 方向键 | 持续平移 |
| Home | 复位到全景 |
| 单击建筑/聚落中心 | 查看详情（右侧面板）+ 聚焦按钮（F） |
| 单击空地 | 查看地形信息（肥力/水气/归属/天象） |

## 三、时间控制

| 按键 | 效果 |
|---|---|
| 空格 | 暂停 / 继续（1×） |
| 1 / 2 / 3 / 4 | 变速（2.0s → 0.18s / 年） |
| 句号 `.` | 单步推进一年 |
| Esc | 取消神力 → 关闭面板 → 打开菜单（层层后退） |

自动存档每 25 年一次；历史快照每 20 年一次（编年史中可分支）。

## 四、神力一览

选择工具后在地图上点击施放。**红框 = 无效目标**；所有神力修改的都是真实模拟变量，有范围与期限。

### 地形类
| 神力 | 消耗(有限模式) | 规则 |
|---|---|---|
| 森林之触 | 5 | 草地/沙地 → 森林；周边草地肥力 +0.05 |
| 沃土化 | 6 | 草地 → 沃土（肥力 0.9，最宜耕作） |
| 清泉涌现 | 8 | 非山地 → 水源；相邻草地肥力 +0.12 |
| 矿脉显现 | 10 | 山地/石地显出铁矿(70%)或金矿(30%)；青铜/铁器/蒸汽/电力需要"接触矿藏" |

### 天气类（3×3 区域，持续 5 年）
| 神力 | 消耗 | 效果 |
|---|---|---|
| 甘霖 | 6 | 区域湿度 +30% → 农田增产、水面波光 |
| 酷旱 | 4 | 区域湿度 −45% → 产量下滑，可能引发饥荒（对敌对聚落……或自找麻烦） |

### 赐福 / 启蒙（作用于聚落）
| 神力 | 消耗 | 效果 |
|---|---|---|
| 丰饶祝福 | 10 | 该聚落 5 年食物产出 +25% |
| 智慧之光 | 12 | 研究池 +10 点（**不能**跳过技术前置） |
| 思想火种 | 9 | 劳动者组织度 +0.10、政治参与 +0.08、不满 −0.06（为变革积蓄力量） |

**模式区别**：自由上帝=无消耗；有限干预=消耗信仰（每年 +2）。事件卡上的介入按钮按当前模式计费（自由模式显示“免费”）。

## 五、事件系统

- 事件 = **条件触发 + 结果计算 + 叙事呈现**。例如饥荒必须满足“连续 2 年摄入 < 需求的 82%”，起因链（存粮/产出/人口）会写在事件卡与编年史里。
- 事件卡（重要性 ≥2）右上弹出：图标、年份、描述、**起因**、**结果**；饥荒/疫病卡附**介入按钮**（甘霖/丰饶祝福等），也可以“静观其变”。
- 编年史（H）按类别过滤：丰歉/饥荒/疫病/技术/迁徙/商贸/冲突/变革/战争/思想/兴衰/治世/环境/聚落/制度。标有 ✦ 的事件表示玩家神迹参与其中。

## 六、编年史与历史分支

1. 打开编年史，底部是**历史节点**按钮（第 20/40/60…年）。
2. 点击某节点 → 确认 → 当前世界先自动保存，然后从该节点的世界+随机数状态载入。
3. 你可以换一种干预策略重玩这一段，之后在观察者模式里对比两条曲线（提示：用**保存/读取**功能手动留档对比更方便）。

## 七、观察者模式（O）

- **总览曲线**：人口 / 粮食存量 / 生产与贸易 / 平均技术 / 基尼 / 动荡。
- **社会结构**：每个聚落的所有制、劳动关系、群体财富份额（堆叠条）+ 基尼轨迹。
- **形态时间线**：每个聚落逐段着色，直观看到 原始→…→资本主义/社会主义 的路径与持续年数。
- **数据总表**：21 项派生量全览（高级玩家/实验用）。
- **模型假设**：每一块机制的公式与免责声明。**游戏数字是模型假设，不是现实结论。**

## 八、给新玩家的三条路线建议

1. **自然史路线**：什么都不做，看到哪年出现第一种非原始形态；记录它为什么出现（观察者→数据总表→土地集中/市场）。
2. **神迹路线**：开局就把一处聚落周围全改成沃土+清泉，对比它与其它聚落 100 年后的人口与技术。
3. **革命路线**：等基尼 > 0.55 后，对苦难聚落连放“思想火种”，看组织度何时跨过临界——改革、骚乱还是革命，由模拟决定。
