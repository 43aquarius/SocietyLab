# Society Lab · 人类社会实验室

一款上帝视角的社会演化沙盒游戏：你创造世界、施加神力，社会按照相互联系的规则自主发展，历史在你意料之外自然发生。

> **核心理念**：让玩家通过画面感受文明，通过事件理解社会，通过选择影响历史，通过重复游玩发现不同的可能性。

---

## 一、运行方法

### 环境要求
- **Godot 4.2 或更高版本**（推荐 4.2/4.3，4.4+ 亦可打开）。游戏使用 `gl_compatibility` 渲染器，对显卡要求很低。
- Windows / Linux / macOS 均可（本工程按跨平台编写）。

### 步骤
1. 安装 [Godot 4.2+](https://godotengine.org/download)（标准版即可，无需 .NET 版）。
2. 用 Godot 打开本目录中的 `project.godot`（导入项目，首次会自动导入全部资源，需数十秒）。
3. 按 **F5**（或右上角 ▶）运行。
4. 命令行验证/测试（可选）：
   ```
   godot --headless --import                 # 仅导入资源
   godot --headless --script tests/TestSimulation.gd --path .   # 运行无头测试套件
   ```

> **诚实声明**：本项目在开发环境中**没有 Godot 运行时**，因此无法在此环境中实际启动游戏。
> 我们做了三层替代验证：
> 1. 全部 33 个 GDScript 通过 `gdtoolkit 4` 的 `gdparse` 语法校验；
> 2. 核心模拟公式以 Python 镜像（`sim_mirror.py`）做了 300 年多种子数值验证；
> 3. `tests/TestSimulation.gd` 提供可在你的机器上真实运行的无头测试（生成确定性、演化弧线、饥荒因果链、五形态识别、存档回路、神力后果、快照分支）。
> 若运行中发现问题，请反馈至项目 issue；已知问题清单见 `docs/已知问题与后续开发清单.md`。

## 二、十分钟上手

1. **主菜单 → 新的世界**：选种子（同种子=同地形）、地形起伏、资源丰度、聚落数量、神力模式（自由上帝/有限干预）。
2. 进入世界后按 **空格** 开始时间流动（1/2/3/4 调速，句号单步，空格暂停）。
3. 观察左侧聚落：滚轮缩放、按住左键拖动平移、`Home` 复位全景；单击建筑/聚落查看详情。
4. 左侧工具栏选择**神力**（森林/沃土/水源/矿脉/甘霖/酷旱/丰饶/智慧之光/思想火种），点击地图施放；红框=无效目标，`Esc` 取消。
5. 重大事件会弹出**事件卡**——可以点按钮介入（例如饥荒时施甘霖），或静观其变。
6. `H` 打开**编年史**：查看每个事件的起因/结果；从历史节点**创建分支**，对比不同干预策略产生的历史。
7. `O` 打开**观察者模式**：人口/粮食/基尼曲线、所有制与劳动关系结构、形态时间线、数据总表、模型假设说明。

## 四、核心设计决策

- **模拟与渲染分离**：模拟内核不知道任何渲染/纹理的存在；渲染只读 `WorldState`。
- **参数集中**：所有可调数字在 `GameConfig.gd`（结构性系数在对应系统文件内文档化）。
- **事件=条件+因果记录**：每个重大事件的“起因”来自当时模拟变量的真实快照，编年史不编造历史。
- **形态=识别而非升级树**：`SocietyClassifier` 用所有制/劳动关系/土地集中/市场/公有/公共服务打分；得分接近判为过渡/混合。**不存在**“某年自动进入某形态”。
- **可复现**：同一种子+同一规则 → 同一初始地形与模拟路径（随机数全部走 `RNGService` 并存档）。
- **分支**：每 20 年自动快照（含随机数状态），编年史里可从任意快照分出平行世界线。

## 六、目录补充说明

- `assets/`：全部程序化生成的原创素材（Python/Pillow 绘制；音频 numpy 合成）。`manifest.json` 是唯一资源清单。
- `docs/`：操作指南、核心模型假设说明、已知问题与后续开发清单。
- `tests/TestSimulation.gd`：无头测试套件（7 组用例）。
- `tools` 目录不存在于工程内——生成脚本在交付包 `dev_tools/` 中（用于再生成素材/字体子集）。
